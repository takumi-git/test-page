③ 与信チェックロジック（実装視点）

与信使用額 =
    売掛残高
  + 受注残
  + 出荷済未請求
  - 入金予定額

If 与信使用額 > 与信限度額 Then
    → 受注登録NG
    → 出荷停止
    → 承認ワークフロー
End If

  • 売上未計上 → 売掛不足
  • 請求漏れ → 回収不能
  • 消込未実施 → 滞留債権
  • 出荷済未請求残高肥大 → 与信NG
